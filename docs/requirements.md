# ikalga.net 要件定義書

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | ikalga.net |
| 種別 | ポートフォリオ Web サイト |
| 目的 | 就職・転職活動でのスキルアピール、個人ブランディング |
| 対象ユーザー | 採用担当者、技術者コミュニティ |
| 言語 | 日本語のみ |

## 2. ページ構成

home / about / resume の3ページ構成。
制作実績は独立ページ化するほどの数がないため、当面 about 内のセクションとして掲載する（増えてきたら `/works/` への分離を検討）。

### 2.1 トップページ (/)

- ヒーロー: 名前（ロゴ） + タグライン + 短いリード文（2〜3行）
- 連絡先リンク: SNS・メール等への丸型リンクボタンを掲載
  - 連絡先の掲載は home のみ（専用 contact ページは作らない）
- 各ページへのナビゲーション

### 2.2 プロフィール (/about)

- 自己紹介文
- スキルセット（言語・フレームワーク・ツールなど）
- 制作実績セクション
  - カード形式（タイトル + 説明 + 使用技術 + 外部リンク）
  - 詳細ページは持たず、GitHub 等の外部リンクへ誘導

### 2.3 職務経歴書 (/resume)

- 以下の構成をベースにする
  1. 個人データ（氏名・ID・Web・連絡先）
  2. 現状（できること / やりたいこと）
  3. 経験した技術と業務領域
  4. プログラミングスキル
  5. 職務経歴（新しい順、会社 + 期間ごと）
  6. 業務外活動
- コンテンツは Markdown ファイルで管理し、ビルド時に HTML 化（Nuxt Content）

### 2.4 共通要素

- ヘッダー: サイト名 + ナビゲーション（home / about / resume）
- フッター: コピーライト（SNS リンクは home に集約するため置かない）

## 3. 技術スタック

| カテゴリ | 技術 |
|----------|------|
| フレームワーク | Nuxt 4 (Vue.js 3) |
| 言語 | TypeScript |
| スタイリング | Tailwind CSS |
| Markdown 変換 | Nuxt Content（経歴等の一部コンテンツを `.md` で管理し、ビルド時に HTML 化） |
| ビルド | Vite (Nuxt 標準) |
| ホスティング | GitHub Pages (静的生成: `nuxt generate`) |
| パッケージ管理 | npm |
| リンター / フォーマッター | ESLint + Prettier |

## 4. デザイン方針

### 4.1 全体方針

- **ミニマル・シンプル** を基調とする
- 余白を十分に取り、コンテンツの可読性を最優先
- 装飾は最小限にし、タイポグラフィとレイアウトで魅せる

### 4.2 カラー

- 背景色: ブランドカラー 1色（ごく薄い青緑色を想定、カラーコードは後日指定）
- テキスト: ダークグレー
- ダークモード対応は初期スコープ外（将来的に検討可）

### 4.3 レスポンシブ

- モバイルファーストで設計
- ブレイクポイント: 768px (タブレット) / 1024px (デスクトップ)

### 4.4 アニメーション

- ページ遷移: View Transitions API によるスムーズなトランジション
- 丸型リンクボタンのホバー演出（破線円が現れる控えめなアニメーション）
- `prefers-reduced-motion` 設定時はアニメーションを無効化する

## 5. 非機能要件

| 項目 | 目標 |
|------|------|
| Lighthouse Performance | 90 以上 |
| レスポンシブ対応 | モバイル・タブレット・デスクトップ |
| SEO | 基本的なメタタグ、OGP 対応 |
| アクセシビリティ | セマンティック HTML、適切な alt テキスト |

## 6. 静的生成 & デプロイ

- `nuxt generate` で静的 HTML を生成
- GitHub Actions で `main` ブランチ push 時に自動デプロイ
- 出力先: GitHub Pages

## 7. スコープ外（将来的に検討）

- 制作実績の独立ページ化（`/works/`）— 実績が増えてきたタイミングで検討
- ダークモード切り替え
- 多言語対応（英語）
- 技術ブログ機能
- お問い合わせフォーム
- CMS 連携
