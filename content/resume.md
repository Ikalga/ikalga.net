#### ポータルサイト アーキテクチャ移行 (2019.12 ～ 現在)

- 下記 Web ポータルサイトについて、PHP (Symfony) から Python (Django) バックエンド + Vue.js フロントエンドへのアーキテクチャ移行を実施しています。
- 新アーキテクチャではAWS ECSとGithub Actionsを組み合わせたCI/CDの仕組みを構築しました。
- 稼働中のサイトにサービス停止を発生させず段階的に移行を進めることができています。
- 新アーキテクチャは2021年に完成。2026年時点でも旧アーキテクチャの利用箇所は残っていますが、バックエンドの通信については多くを新アーキテクチャに委譲できています。
- アーキテクチャの移行理由:
  - フロントエンドの実装においてモジュール化の度合いが低かったため、Vue.js による再利用性が高いコードに変更したかったこと。
  - Symfony の ORM 機能に不満があり、DBマイグレーション機能等の充実したFWに移行したかったこと。
  - 依存するミドルウェアにて後方互換性の損なわれるバージョンアップがあり、単純なアップデートでの追従が困難になったこと。
- 使用言語: Python, JavaScript (Vue.js)
